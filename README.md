# E-Commerce Sales Analysis – Excel Project

## Project Overview

This project is an E-Commerce Sales Analysis project created using Microsoft Excel.

The project analyzes e-commerce sales data to understand sales performance, order trends, customer demographics, order status, gender-wise sales, and other business insights.

## Dataset

The dataset contains e-commerce order information including:

- Order ID
- Customer ID
- Gender
- Age
- Date
- Order Status
- Sales Channel
- SKU
- Category
- Size
- Quantity
- Amount
- Ship City
- Ship State
- Postal Code
- Country
- B2B

## Excel Skills Used

- Data Analysis

- Pivot Charts

## Analysis Performed

### 1. Monthly Sales Analysis
Analyzed total sales and order count month-wise using Pivot Tables.

### 2. Gender-wise Sales Analysis
Analyzed sales contribution based on gender.

### 3. Order Status Analysis
Analyzed orders based on different statuses such as:

- Delivered
- Cancelled
- Returned
- Refunded

### 4. VLOOKUP Analysis
Used VLOOKUP to find the shipping city based on Order ID.

### 5. XLOOKUP Analysis
Used XLOOKUP to find the sales channel based on Customer ID.

### 6. Sales Calculations
Calculated:

- Average Sales Amount
- Maximum Sales Amount
- Minimum Sales Amount

## Dashboard

Created an interactive Excel dashboard to present important sales and order insights in a visual format.

## Key Learning

Through this project, I practiced working with a large e-commerce dataset and developed practical skills in Excel data analysis, Pivot Tables, lookup functions, formulas, charts, and dashboard creation.
